# Проектная работа 7 спринта

 **В качестве базы знаний выбран фандом по мирам братьев Стругацких с сайта science.fandom.com.**

Взяты документы по персонажам (26 документов) и паланетам (19 документов).
Произведено переименование персонажей и планет с помощью скрипта rename.py по маппингам в файлах mapping.json и planets_mapping.

Векторный индекс по базе знаний будем хранить в ChromeDb, поднятой в контейнере в докере.
Для построения векторного индекса используем модель **ai-forever/sbert_large_mt_nlu_ru** (также пробовал модели all-MiniLM-L6-v2, sentence-transformers/LaBSE, cointegrated/rubert-tiny2) - поиск по векторной базе, построенной с помощью этой модели, на мой взгляд, даёт наиболее адекватные результаты.

Скрипт построения индекса- build_index.py
    Этот скрипт также поднимает контейнер ChromeDb с помощью docker-compose, и контейнер ollama с загрузкой модели gemma2:2b
Скрипт проверки качества - check_quality.py

Для разбиения на чанки используем **tiktoken** для токенизации и **RecursiveCharacterTextSplitter** для чанков при параметрах размера чанка=200 и пересечение 30. Получился 201 чанк.

Создание индекса занимает порядка 40 секунд.

Для RAG бота используется скрипт rag_search.py с локальной моделью в докер-контейнере **gemma2:2b**
(также пробовал модели tinyllama, gemma:2b, phi3:mini)
